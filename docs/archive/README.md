# Archive

These docs describe Anvay's **pre-pivot direction**: a generic Perplexity-style
research assistant (web search + validator agent + RAG, Google OAuth, Docker
Postgres + pgvector, single-user, no teams).

On 26 August 2026 the product pivoted to a **financial research copilot** for equity
and investment analysts. See the current docs instead:

- [`../PRD.md`](../PRD.md) — product definition
- [`../MVP.md`](../MVP.md) — v1/v2/v3 scope
- [`../IMPLEMENTATION-PLAN.md`](../IMPLEMENTATION-PLAN.md) — engineering phases and stages

Kept here for historical reference only. Do not build against these files — several
of their decisions (Google OAuth, pgvector, enterprise/team-first framing) were
explicitly reversed in the pivot.
